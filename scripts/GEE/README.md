# Google Earth Engine processing

All Earth Engine processing in this study was written with the Earth Engine Python API and executed in Google Colab. The original pipeline is in `../Colab` (01 annual RSEI computation, 02 missing-year audit, 03 re-processing of missing years, 04 pixel-wise Mann-Kendall / Sen's slope trends); the review analyses that also run on Earth Engine are scripts 05-13 and 19 in `../RSEI`, `../Trend_Analysis` and `../Figure_Generation`. No JavaScript Code Editor scripts were used.
