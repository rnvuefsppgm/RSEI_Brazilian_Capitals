# R

No R code was used to produce the published results. The original submission mentioned the R package `trend`; the pixel-wise Mann-Kendall / Sen's slope analysis was in fact implemented in Earth Engine (`../Colab/NEW_Trends_RSEI_2026_Luana_V3_multiplos_assets__b.ipynb`), and the sensitivity analyses in Python (`pymannkendall`). Two small R helper scripts used only to organise exported files locally are not part of the scientific workflow and were not published.
