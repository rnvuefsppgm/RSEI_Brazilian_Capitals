# R

No R code was used to produce the published results. The original submission mentioned the R package `trend`; the pixel-wise Mann-Kendall / Sen's slope analysis was in fact implemented in Earth Engine (`../Colab/04_pixelwise_mann_kendall_sen_trends.ipynb`), and the sensitivity analyses in Python (`pymannkendall`, script 09). Two small R helper scripts used only to organise exported files locally are not part of the scientific workflow and were not published.
